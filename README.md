# Sudden Skills

## Install the Skill

Teach your agent how to integrate, configure, and implement Sudden:

```sh
npx skills add sudden-network/skills
```

This installs [the skill](https://github.com/sudden-network/skills/blob/main/skills/sudden/SKILL.md) into your project and makes it available to your agent when working with Sudden.
